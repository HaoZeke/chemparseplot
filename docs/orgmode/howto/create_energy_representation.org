#+OPTIONS: toc:nil num:nil

* Problem

The GP has to interpolate a field the figure can be read by. Occupancy
invert is a histogram diagnostic, not that field.

For a NEB path the field is potential energy on RMSD =(r, p)= /
=(s, d)= (MethodsX). For a landfold χ map the field is a structural
order parameter on the high-D descriptors that built the map: the
fcc/ico basin coordinate of the n4..n13 coordination counts for LJ38.

* Representation

The plane is RMSD =(r, p)= / =(s, d)=, or a landfold =(s1, s2)= map.
The field is potential energy on a path, or the basin coordinate
=ξ = d(x,a)/(d(x,a)+d(x,b))= of high-D descriptors on a χ map.
Path gradients come from =F_parallel= along the Savitzky-Golay tangent.

#+begin_src python
from chemparseplot.parse.representation import from_path_forces, load_energy_table
from chemparseplot.plot.representation import plot_energy

# NEB / TSE path: (r, p, E, F_parallel) -> E(s, d)
rep = from_path_forces(rmsd_r, rmsd_p, energies, f_para, frame="rmsd")
fig = plot_energy(rep, method="grad_imq")
fig.savefig("energy_sd.png", dpi=170, facecolor="white")

# Landfold χ plane: basin coordinate of high-D descriptors
from chemparseplot.parse.representation import from_descriptor_cloud

rep = from_descriptor_cloud(s1, s2, cn_counts, ref_a=cn_fcc, ref_b=cn_ico)
fig = plot_energy(rep, method="rbf")
#+end_src

The table is =chemparseplot.energy.v1=::

  # x y energy [f_para] [step]
  0.0 2.1 -173.9 0.02 0

Dispatch a precomputed field table::

  rgpycrumbs landfold plot-energy --input cloud.energy.csv \
      --output xi.png --frame landfold --method rbf --clabel '$\\xi$'

* What this is not

=plot_fes= / =rgpycrumbs landfold plot-fes= fit occupancy
(=-kT ln(rho/rhomax)=). That is a sampling diagnostic. It is not the
energy representation.
